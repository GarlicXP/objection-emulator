# 律师选择器（桌面悬浮效果软件）

在桌面上运行的“选择律师”互动软件：启动后出现小尺寸窗口选择界面，选定律师后，
在桌面任意位置产生带透明通道的悬浮视频与图片效果（含声音）。

**项目完全自包含**：全部代码、素材（含图标 `media\lsxz.webp`、背景音乐
`media\bgm.mp3`）都在本文件夹内，把整个文件夹拷到任意位置即可运行或编译，
**不依赖 `D:\项目` 等外部路径**。

## 运行方式

- **双击 `start.bat`**（首次运行会自动创建虚拟环境并安装依赖，之后秒开）。
- 手动运行：`python main.py`（或 `.venv\Scripts\pythonw.exe main.py`）。
- 程序日志写入同目录 `app.log`。

## 编译为 exe

- **双击 `build_exe.bat`** 即可编译（缺虚拟环境时会自动创建并安装依赖，
  网络抖动自动重试；产物：`dist\律师选择器.exe`）。
- 产物为单文件、免安装、约 98MB，**全部素材已内置**，可独立运行。
- 排错自检：`dist\律师选择器.exe --selftest`（结果写入 exe 同目录 `app.log`）。
- 替换素材：直接改 `media\` 里的文件后重新编译即可。

## 使用说明

### 1. 选择界面（窗口形态、小尺寸、视频静音、有背景音乐）
- 弹出约 960×680 的小窗口（可拖拽、可缩放），背景**左半区深蓝色、右半区深红色**，
  标题「请选择您的律师」，并播放 `D:\项目\bgm.mp3`（开始淡入，选完后淡出停止）。
- 左右各一个视频区，**启动时立即**以 **0.5x 速度灰色循环**播放 14 / 24
  （无需等待鼠标靠近）。
- **鼠标靠近**左侧视频本身：去掉灰度播放彩色 15；靠近右侧视频本身：播放彩色 25。
  判定**严格按视频区域**（仅视频边缘外 20px 内算“靠近”，不再按窗口左右半区），
  带滞回防快速滑动闪动；两侧都不靠近时始终都是灰色，**包括已被选中的那一侧**
  ——选中只产生选框，不改变视频颜色。
- **点击视频选中律师**：从鼠标点击点开始扩散出一个白色选框，0.5 秒内扩大到视频
  边缘并停留；点击另一个律师可随时换选（旧框消失、动画重播，可打断）。
- **16 / 26 只会在“换选”时播放**：选中的状态下不主动播放，只有在选中另一个律师
  来回切换时，旧的律师才以灰色播放一次 16 / 26，然后回到灰色 14 / 24 循环。
- 点「确认选择」结束选择（按钮在选中后才可用）：画面**先定格暂停约 0.4 秒**，
  再出现矩形缩小动画（0.8 秒），从边框向中心缩小消失。
- 选择界面的视频全程无声音（bgm 除外）。

### 2. 选中后的桌面效果（持续生效，可叠加，效果视频**带声音**）
- **鼠标左键**：`lsxz.png` 在所选律师对应的半屏内随机位置出现（**较大尺寸，约
  520px 宽**），**边旋转边缩小飞向鼠标点击点**，到达点击点时尺寸归零消失；
  同时在该半屏随机位置播放 13 / 23 透明视频（带声音，音频播完才清理）。
  每按一次左键重现一次，可叠加。
- **鼠标右键**：**只要按下就触发**，在所选半屏随机位置播放 11 / 21 透明视频（带声音）。
- **桌面出现新窗口**：在所选半屏随机位置播放 12 / 22 透明视频（带声音）。
- 效果视频（11/12/13/21/22/23）**显示为原尺寸的一半**（原 640×360 → 显示 320×180）。
- 所有浮层均为透明、置顶、不拦截鼠标的纯视觉层。

### 3. 系统托盘（选完后常驻后台）
- 确认选择后程序进入**系统托盘后台运行**，托盘图标使用 `D:\项目\lsxz.webp`
  （带透明；文件缺失时回退用 `media\lsxz.png`）。
- **右键托盘图标**：菜单提供「重新选择律师」（重新弹出选择界面，可换人后继续
  桌面效果）与「退出」（彻底退出程序）。

### 4. 退出
- 选择界面按 `Esc` 退出程序。
- 进入桌面效果模式后，按 **Ctrl+Shift+Q** 退出程序（进入效果模式时屏幕右下角
  会短暂显示该提示，约 8 秒后自动淡出）。
- 或者**右键托盘图标 → 退出**。
- 实在找不到进程时：程序是无窗口的 `pythonw.exe`，在任务管理器「详细信息」标签
  按名称找 **pythonw.exe**（显示名为 Python），结束任务即可；或在 CMD 执行
  `taskkill /F /IM pythonw.exe`。

```
├── config.py          配置：媒体映射、颜色、参数（全部指向本目录 media\）

├── overlay.py         桌面效果浮层（图片旋转飞行、带声音的透明视频、托盘提示）
├── monitors.py        全局鼠标钩子、桌面新窗口监听、退出快捷键
├── media_player.py    视频解码渲染控件（透明合并/灰度/倍速/循环/音频）
├── convert_alpha.py   透明视频 → 双轨 WebM 转换脚本（维护用，需系统 ffmpeg）
├── build_exe.py / build_exe.bat   一键编译为单文件 exe
├── test_functional.py / test_monitors.py   自动化功能测试
├── start.bat          一键启动（自动创建 venv 并装依赖）
├── requirements.txt
├── media/             全部素材：11-26 视频、lsxz.png / lsxz.webp（图标）、bgm.mp3
└── dist/              编译产物：律师选择器.exe
```

> `convert_alpha.py` 是素材转换维护工具（把带透明的 .mov 转成双轨 WebM），
> 需要系统已安装 ffmpeg 且加入 PATH；日常运行与编译不需要它。

## 媒体素材说明（透明通道核查与转换）

**核查结果**：原始 `11/12/13/21/22/23.mov`（QuickTime 动画编码，像素格式 argb）
**确认带真实透明通道**（alpha 值范围 0~239），且带 pcm 立体声音轨。

**转换方案**：原始每段约 9~12MB，已转换为**双轨 VP9 WebM + Opus 音轨**（每段约
60~75KB，体积缩减约 99.5%，透明效果与原片一致，音频保留）。

> 为什么不用“标准 alpha WebM”：WebM 的标准透明方式是把 alpha 码流作为每帧的
> BlockAdditions 附加数据，而 FFmpeg 无论封装还是解码都处理不了这一机制（解码器只会把
> AlphaMode 导出为元数据，不会还原透明通道）。因此本工具把**主画面（RGB）与 alpha 平面
> 分别编码为两条 VP9 视频轨**装入一个 WebM，播放端在运行时合并为 RGBA——这是
> FFmpeg/PyAV 技术栈下唯一可行的“WebM + 透明”方案。
> 如果你希望得到**浏览器可直接播放的标准 alpha WebM**，需要 Chrome/官方 libwebm 工具链，
> FFmpeg 无法生成。

- `14/15/16/24/25/26.mp4`（720×720，选择界面用，无透明需求）原样保留。
- 替换素材：保持同名放入 `media/` 即可；透明视频放 `.webm`（双轨）或原 `.mov` 均可
  （播放器两者都能读，mov 会慢一些）。

## 说明与已知限制

- 效果基于主显示器；多显示器下按主屏缩放比折算（建议系统缩放 100% 体验最佳）。
- “桌面出现新窗口”通过轮询顶层窗口实现（约 0.3 秒），不含本程序自身的浮层。
- 若需开机自启，把 `start.bat` 的快捷方式放入「启动」文件夹。
